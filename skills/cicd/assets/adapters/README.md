# Task-interface templates

These are optional adapters for the logical CI/CD contract.

Use only the adapter that matches the repository's existing or explicitly chosen task interface.

The templates are starting points, not universal requirements.

Select `LOCAL`, `REMOTE`, or `HYBRID` from repository requirements. `docker-jobs-local.md.template` documents an optional local Docker adapter. Remote provider configuration is not templated because it depends on the selected provider and repository policy.
